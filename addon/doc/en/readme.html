WhatsApp Desktop Access

An NVDA add-on that improves the accessibility of WhatsApp Desktop for Windows: the Microsoft Store app built on WinUI 3 and WebView2.

Keyboard commands

  • Alt+1: move to the chat list. The focus goes to the open chat, or to the first chat.
  • Alt+2: move to the message list. The focus goes to the newest message.
  • Alt+D: move to the message field.

These keys are not used by WhatsApp itself. The commands find their targets by role, so they work in every WhatsApp language and keep working when WhatsApp changes its page markup. If a target is missing, for example when no chat is open, NVDA says so.

You can assign other keys in NVDA's Input Gestures dialog, under "WhatsApp Desktop Access".

Keeping the focus on the message field

The add-on keeps NVDA on the message field while you type.

Without this add-on, NVDA can lose the message field after you select and delete text. NVDA announces "menu", then "pane", and stops echoing typed characters and reporting the caret until you press Tab and Shift+Tab to return to the field.

The add-on prevents this in two ways:

  • WhatsApp shows a small popup with the role "menu" next to selected text. NVDA used to move its focus to that popup, although the real keyboard focus stays in the message field. The add-on ignores the popup while an edit field in the page has the focus.
  • When the popup closes, NVDA used to land on the window pane that hosts the page. The add-on returns the focus to the element that really has it inside the page. If that is the element NVDA already had, nothing is announced again.

The add-on builds on NVDA's own WhatsApp support, which turns browse mode off by default.

Requirements

  • NVDA 2026.1 or later. Tested with NVDA 2026.2.
  • WhatsApp Desktop from the Microsoft Store on Windows 11. Tested with version 2.2638.102.0.

Other WhatsApp add-ons

NVDA loads only one WhatsApp app module. If another WhatsApp add-on that includes an app module is installed and enabled, such as WhatsApp NG or WhatsApp Desktop Enhancer, disable it while you use this add-on.

Current limits

Version 1.0 fixes the focus problem and adds the three navigation commands. Reading messages, playing voice messages and reducing repeated announcements are planned for later versions.

Changes

Version 1.0.1

  • Added contact details: this help and the homepage link lead to the author's website, where there is a contact form. There is no change in behavior.

Version 1.0.0

First version for the NVDA add-on store.

  • Added Alt+1, Alt+2 and Alt+D to move to the chat list, the newest message and the message field.
  • Each command says so when there is nothing to move to, for example when no chat is open.
  • The commands find their targets by role, so they work in every WhatsApp language and keep working when WhatsApp changes its page markup.
  • The commands remember what they found, so repeated use is instant. The first Alt+2 in a chat still takes about a second.
  • Added a Hebrew translation of the command names and messages.

Version 0.1.0

First public version, published on GitHub only.

  • NVDA no longer loses the message field after you select and delete text. Before, NVDA announced "menu" and then "pane", and stopped echoing typed characters until you pressed Tab and Shift+Tab to get back into the field.

The full list is in the changelog on GitHub.

The source code and the issue tracker are on GitHub.

Diagnostics

The log lines written by this add-on start with "WA-GUARD" (focus handling) or "WA-NAV" (navigation commands). They never contain message text.
